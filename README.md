# Minecraft Survivor Scrips

This repo contains programs for CC:Tweaked. Anything in `programs/` gets installed to `/bin` on the computer, and shared modules in `lib/` go to `/lib`.

## Installation

On a computer (in minecraft), run:

```
wget https://raw.githubusercontent.com/xalayn/minecraft-survivor-scripts/HEAD/install.lua install
install
```

Running `install` again later will pull the latest version.
